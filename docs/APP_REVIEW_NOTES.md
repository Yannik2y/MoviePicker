# App Review Notes — 007 Film Picker

Paste a shortened version into App Store Connect → App Review Information → Notes.

## Summary

007 Film Picker is an **unofficial** fan catalog picker. It is **not** affiliated with, endorsed by, or licensed by Eon Productions, MGM, Danjaq, or the James Bond franchise.

Primary experience: **Bond Picker** (random official Bond film titles from an on-device catalog).  
Also includes Movie Picker (host-selected film) and Dad Mode (always WM-Halbfinale 2014).

## How to find Host tools (Movie Picker)

1. Open the **Pick** tab.
2. Switch the segmented control to **Movie Picker**.
3. Tap the **ellipsis** toolbar button → **Host tools**.
4. Search TMDB and select a film. The reveal always lands on that selection.

(VoiceOver: Host tools is labeled and reachable from the Pick toolbar.)

## Privacy

Policy URL: host [`PRIVACY.md`](../PRIVACY.md) publicly (e.g. GitHub Pages / raw main) and paste that HTTPS URL into ASC.

The app sends search queries and poster requests to TMDB; history/favorites stay on-device. No tracking SDKs.
